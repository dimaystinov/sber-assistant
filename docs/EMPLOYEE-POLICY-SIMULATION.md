# Открытые корпоративные правила для симуляции сотрудника

Проверено 9 ноября 2026 года. «Внутренний регламент» означает правило для работников организации; некоторые такие документы опубликованы самой организацией. Публикация не превращает документ в пошаговую инструкцию для каждой кадровой или банковской операции. Проект использует только законно опубликованные источники и отдельные вымышленные сценарии.

## Реализованный учебный кейс

В `assistant/knowledge.py` добавлен документ `demo-employee-gifts`: вымышленный поставщик предлагает подарок сотруднику учебного банка. Ассистент должен найти учебный документ, пояснить, что решение не принимается автоматически, и предложить создать учебное обращение к комплаенс-специалисту через уже существующий инструмент `create_support_ticket`. До подтверждения пользователя обращение не создаётся. Источник и ответ маркируются как `ДЕМО`; конкретные нормы Сбера и лимиты подарков не выдумываются.

Примеры запросов для демонстрации:

- «Поставщик предложил подарок. Что делать в учебном кейсе?» → `demo-employee-gifts`, ответ с пометкой вымышленного банка.
- «Где посмотреть настоящие правила Сбера о подарках?» → ссылка на опубликованный Кодекс этики и передача вопроса комплаенс-специалисту; без утверждения о непубликованных порогах.
- «Как оформить отпуск по внутреннему регламенту Сбера?» → учебный порядок не должен выдаваться за действующий ВНД; для реального ответа нужен документ владельца HR-процесса.

## Шаблон для будущего ВНД

Для каждого загружаемого документа нужны: `organization`, `document_type`, `source_url`, `owner`, `approved_by`, `version`, `effective_from`, `effective_to`, `role`, `department`, `access_level`, `checksum`, `supersedes`, `reviewed_at`. Поиск сначала проверяет организацию, полномочия и срок действия, затем извлекает нужный пункт. Если инструкция конфликтует с законом, договором или другой действующей редакцией, ответ блокируется и передаётся ответственному человеку. Публичные документы другого банка хранятся только как сравнительные примеры в отдельной коллекции.
