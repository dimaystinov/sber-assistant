# Базовые сравнения

| Сравнение | Какой тезис проверяет | Статус |
|---|---|---|
| Текущий процесс без ИИ | Реальная польза и время | Требует полевого пилота |
| GigaChat без внешнего gate | Вклад программной проверки | Частично: один обнаруженный финансовый черновик и регрессионный тест |
| Lexical retrieval | Точность на точных формулировках | Выполнено |
| GigaChat-3-Lightning как роутер по документам роли | Устойчивость к перефразировкам | Выполнено на 10 случаях |
| EmbeddingsGigaR + lexical hybrid | Семантический RAG при большом корпусе | Не выполнено: API вернул 402 |
| Критик включён/выключен | Вклад независимой проверки | Требует размеченного набора ответов |
| Broker включён/выключен | Защита от опасного действия | Сравнение с небезопасным режимом только в закрытой симуляции; не запускать на реальных системах |
